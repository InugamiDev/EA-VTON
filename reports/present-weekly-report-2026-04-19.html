Research Core

Size recommendation là phần nghiên cứu chính

Bài toán và hướng giải quyết
  • Data source khác target users, nên model dễ bias khi học trực tiếp.
  • Hướng giải quyết là re-weight data theo target users, thay vì bỏ dữ liệu cũ đi.
  • Hai model family được so sánh trực tiếp là GBM và MLP.
  • Copula giúp modeling height và weight jointly; PSIS giúp giảm ảnh hưởng của outliers.
  • Output cuối của nhánh này là size, confidence và measurements.

Phương pháp cho nhánh size

Source Dữ liệu huấn luyện hiện có

Giữ lại các feature chính như height, weight, BMI, age, body type và category.

Target Target users / prior VN

Dùng thống kê mục tiêu để điều chỉnh phân bố học thay vì train trực tiếp.

Re-weight source data theo target users
Joint Modeling Copula density ratio

Modeling height và weight cùng nhau để phản ánh đúng mối liên hệ giữa hai biến.

Tail Control PSIS smoothing

Làm mượt tail của weight để các điểm quá cực đoan không làm lệch model.

So sánh model family rồi chọn candidate thực dụng
Model A GBM

Baseline mạnh và ổn định nhất trên dữ liệu bảng hiện tại.

Model B MLP

Dùng để kiểm tra neural model có thắng thật hay không.

Output Size + confidence + measurements

Đầu ra cuối cho recommendation service.

Equation A Copula density ratio

Cho phép reweight source data theo target distribution thay vì giả định hai biến độc lập.

Equation B Weighted loss

Weight được đưa trực tiếp vào loss để model ưu tiên target users.
